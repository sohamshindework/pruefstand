# Security

Prüfstand is a development and research tool. Custom agents execute trusted Python code in process unless you deliberately launch a container. Fault injection can cause repeated side effects; use isolated test tools. Do not run it against real payments, production workflows, or untrusted code with your normal credentials.

The localhost JSON proxy is not an authenticated production gateway. Trace storage has no application-level access control or encryption. Pattern-based screening cannot guarantee removal of all sensitive data. Keep stores and exported evidence private until reviewed.

To report a vulnerability, use the repository’s private vulnerability-reporting feature when available. Otherwise open an issue asking for a private contact without disclosing exploit details, secrets, customer records, or identifiable third-party findings. No response-time guarantee is currently offered.
